Components

Button 按钮

高度 48px（大）/ 40px（中）/ 32px（小），全圆角胶囊，支持蓝色实心、橙色实心、描边、幽灵四种变体。

实色按钮 Solid

用于主操作（提交/确认），蓝色为品牌主色，橙色用于警示/强调操作。

HTML
<button class="btn btn-primary">Primary</button>
<button class="btn btn-orange">Orange</button>

描边 & 幽灵按钮 Outline / Ghost

描边按钮用于次要操作（取消/返回），幽灵按钮用于三级操作（详情/查看）。

HTML
<button class="btn btn-outline">Outline</button>
<button class="btn btn-ghost">Ghost</button>
